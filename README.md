# Các Dev clone project từ github sẽ cần setup như sau
## Bước 1
- composer install

## Bước 2
- cd web/app/themes/my-theme
- composer install
- npm install

## Bước 3
- npm run dev

## từ my-theme: cd .. 2 lần để về lại web/app

## Bước 4
- cd web/app/plugins/b2b-core
- composer init -n
- composer require firebase/php-jwt
- composer require phpmailer/phpmailer

## Bước 5
- Thực hiện setup file README.md trong b2b-core / my-theme để bắt đầu code
