This project is developed on top of the Roots Sage/Bedrock framework and extends the WordPress ecosystem into a custom B2B Marketplace platform specialized for used-car trading between enterprises.

The system architecture, custom database schema, REST API workflow engine, State Machine processing logic, Escrow simulation flow, and core business modules were independently researched, designed, and implemented as part of a graduation thesis project.

Project Name: B2B Oto Marketplace
Official Domain: sanotob2b.com
